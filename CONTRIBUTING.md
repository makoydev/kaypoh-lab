# Contributing

1. `npm install`, then `npm run check` before and after your change (lint, typecheck, tests, build).
2. Read `CLAUDE.md` — it is the working guide for humans too: the build system, the testing rules, and
   where creative freedom is welcome.
3. Adding a module? Follow `docs/ADDING_A_MODULE.md`.
4. Made a lasting decision? Add two lines to `docs/DECISIONS.md`.
5. Touched anything in `src/components/3d`, `src/components/canvas`, or the Workshop? Run the visual QA
   checklist in `docs/TESTING.md`.

Commit messages: short imperative subject, body explains *why* when it isn't obvious.
